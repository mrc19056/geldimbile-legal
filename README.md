gizlilik politikası.

Politika Türkçe ve İngilizce olarak tek sayfada yer alır.

## Özet

Uygulama **hiçbir kişisel veri toplamaz**. Tamamen çevrimdışı çalışır,
internet izni bile istemez. Tek izin `VIBRATE` (titreşim geri bildirimi).
Oyun ilerlemesi yalnızca cihazda saklanır.
